# Cricket Legends V11 — Coins, Compatibility & Tactics

This version builds directly on the hosted Stadium Lights game.

- Season rewards: finish 20 matches to receive the highest achieved tier (10/12/15/18/20 wins = 10/25/50/100/200 coins). Credits accumulate locally.
- Spend 200 earned coins to reroll both the country and decade for the current draft turn without losing selected players. Existing free one-country/one-era rerolls remain.
- Draft suggestions: player-fit rankings depend on your selected XI, batting positions, bowling options and keeper coverage. Switch between fit-first and original random order.
- Detailed pre-/post-season squad report: 20-over bowling coverage, powerplay balance, batting depth, keeper, pace/spin strategy and caveats.
- Historical source figures remain separate from fictional ratings and game simulation.
- Local coins are not server-verified and do not affect online leaderboards or involve payments.

Data-backed principles: https://www.icc-cricket.com/news/mens-t20i-match-clause-13-innings and https://www.mdpi.com/2076-3417/15/19/10341.

`npm start` starts the game and existing multiplayer API. `npm test` checks the backend.
