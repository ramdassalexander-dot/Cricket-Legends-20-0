# Cricket Legends 20–0 V20 Captaincy Upgrade

Live: https://cricket-legends-20-0.onrender.com

New: phase-specific captaincy tactics (batting risk, bowling aggression, pace/spin preference), locked season strategy, match reports, seasonal badges, daily squad preview and shareable XI challenge links.
